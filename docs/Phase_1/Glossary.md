# Glossary

***

*Glossary for terms used in the [documentation](https://moodle.isep.ipp.pt/pluginfile.php/311233/mod_resource/content/6/LETI-ESOFT23-24-ProjectAssignment.pdf) provided in relation to the business*


| **_TEA_**                           | **_Description_**                                                                                                                                                                                                                                            |                                       
|:------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Administrator**                   | Person that maintains and configures the core information stored in the application required for normal operation by all entities.                                                                                                                           |
| **Barcode**                         | A form of identification that is generated by an external api.                                                                                                                                                                                               |
| **Client**                          | Person that gets prescribed a lab order, if it's a new one it must be registered in the system by a Receptionist.                                                                                                                                            |
| **Clinical Chemistry Technologist** | Person in charge of performing chemical analysis of the samples collected by the MLT and recording them in the system, for each parameter its recorded the time and date of the analysis.                                                                    |
| ***CLT***                           | Acronym for Clinical Chemistry Technologist                                                                                                                                                                                                                  |
| **Laboratory**                      | Location where tests are performed and recorded.                                                                                                                                                                                                             |
| ***Lab***                           | Abbreviation for Laboratory.                                                                                                                                                                                                                                 |
| **Lab Order**                       | File with the type of test to be performed and parameters to be measured.                                                                                                                                                                                    |
| **Medical Lab Technician**          | Person that records the samples and associates them with a client/test and identifying the samples with a bar code to be sent to the system.                                                                                                                 |
| ***MLT***                           | Acronym for Medical Lab Technician                                                                                                                                                                                                                           |
| **Parameter**                       | Each type of measurement used for the test and is associated with a unique code, name, description, metric and reference values if possible.                                                                                                                 |
| **Receptionist**                    | Person that receives Clients details and registration new clients into the system.                                                                                                                                                                           |
| **Specialist Doctor**               | Person that makes a diagnosis and a report with the information given by the CCM, being it only available to the client after it has been prepared by the specialist.                                                                                        |
| **System**                          | Place where information is stored and passed through.                                                                                                                                                                                                        |
| **Test**                            | Activity performed to the client and is associated with the Lab and date where the Test will be conducted and where the samples will be collected, characterized by an internal code, NHS code and description that identifies the sample collection method. |
